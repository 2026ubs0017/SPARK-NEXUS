# SPARK-NEXUS
Spark-Nexus: An affordable, non-invasive myoelectric prosthetic hand for transradial amputees. Integrates forearm sEMG control with a single-motor underactuated whiffletree mechanism for adaptive grasping. Built on a Fusion-designed, FEA-optimized, CNC-milled Aluminum 6061-T6 skeletal hub.
